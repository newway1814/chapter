# Domain Glossary

- **Chapter**: A rolling 30-day compilation of a user's voice entries, generated by AI into a text-and-charts narrative. It acts as the long-term reward for consistent journaling. (Not tied to a calendar month). Requires a minimum of 10 valid Entries to generate; otherwise, the user is prompted to keep recording until they hit the threshold.

- **Entry**: A daily recording of up to 60 seconds. To be valid and consumed, the Whisper transcript must meet a minimum word count (e.g., 5 words). Short noise/accidental recordings are rejected to save AI credits.

- **Instant Insight**: A single, beautiful AI-generated sentence about the user's entry, shown immediately after transcription. This is the immediate reward that drives daily retention. Generated by Gemini in the Post-Entry Call.

- **Interviewer Question**: A personalized follow-up question generated for *tomorrow's* prompt, based on today's entry. Saved silently to the database. Shown at the top of the recording screen the next day so the user never faces a blank page. Generated in the same Post-Entry Call as the Instant Insight.

- **Post-Entry Call**: A single Gemini API call triggered after a valid transcription. It returns both the Instant Insight and the Interviewer Question in one response (see ADR-0001). This halves latency and API cost vs. two separate calls.

- **Ephemeral Audio**: Raw audio files are deleted immediately after Whisper transcription. They are never persisted to Supabase Storage or any other service (see ADR-0002). The app only stores the text transcript.
